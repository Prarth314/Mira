# Native acceptance matrix

Snapshot: November 1, 2026. Record build/commit, hash, exact OS/architecture, microphone and destination versions, expected behavior, actual behavior and evidence for every additional run. A CI label is not an architecture claim; workflows print their actual runtime architecture. Unperformed rows remain unperformed.

Native paste is still **attempted** in the product. Fixture receipt was verified only because the test owns and inspects the destination. Application PID/window checks cannot prove a particular assistant chat field is focused; focus races, OS activation restrictions and PID/window reuse remain limitations. Terminal controls are rejected before native input; keyboard scripts never include instruction text or Enter. No delayed clipboard restoration is scheduled.
